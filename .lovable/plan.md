# CareerPilot AI — Career Agent Console

A single-flow web app: upload a resume PDF, name a target role, watch five AI agents run in sequence, then read a consolidated career report. No sign-in, nothing stored between visits.

## What the user does

1. Lands on the console, drops a resume PDF and types a target role (e.g. "Full Stack Developer").
2. Presses Run — the agent pipeline starts and each agent lights up as it finishes.
3. Reads the results: readiness score, skill triage (strong / partial / missing), prioritized learning roadmap, and an application kit with a generated cover letter they can copy.
4. Can start a fresh run at any time.

## The five agents

| Agent | Produces |
| --- | --- |
| Resume Analysis | Structured profile: skills, education, projects, experience |
| Job Requirements | Typical requirements for the entered role, generated by AI |
| Skill Gap | Each competency scored and classified strong / partial / missing |
| Learning Roadmap | Prioritized weekly plan with topics, hours, and a capstone project |
| Application Kit | Cover letter, resume improvement notes, interview topics, checklist |

Each agent receives the previous agents' output as shared state, so later steps build on earlier ones — this is the agentic workflow the report describes. Progress is streamed to the screen as it happens; a failed step is shown plainly with a retry, never a silent blank.

## Design

Build the selected "Signal Console" direction exactly: near-black console background, panelled cards, mint/cyan/violet/amber/coral status colors, Space Grotesk display type with IBM Plex Mono for labels and metrics. Left column holds the agent pipeline and the parsed resume summary; right column holds the report — score tiles, skill-gap bars, roadmap timeline, and application kit cards. Same layout, same pulse animation on the active agent.

Before a run, the right column shows the upload/role entry surface in the same panel language; during the run it fills in progressively.

## Technical section

- Stack: TanStack Start + Tailwind v4 tokens in `src/styles.css`, fonts loaded via `<link>` in `__root.tsx`.
- Single route at `/` (replaces the placeholder index) with its own title/description/OG tags.
- PDF text extraction runs in the browser with a client-side PDF text library, so the file never needs uploading anywhere.
- Five server functions in `src/lib/agents.functions.ts`, one per agent, each calling Lovable AI (`openai/gpt-6-astra` via the gateway Responses API, streaming) with a strict JSON schema for its output. The client calls them in order, carrying the accumulated state forward, and renders each result as it arrives.
- Gateway failures (rate limit, credits, config) surface as readable messages in the pipeline panel per the gateway error contract.
- No database, no auth — run state lives in React state only.
- Cover letter copy uses the clipboard API.

## Not included in this version

- Saved history, accounts, LinkedIn/GitHub analysis, job tracking, real live job postings (requirements are AI-generated from the role name).
